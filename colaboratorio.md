# *GOOGLE COLAB*

Es un servicio de goolge para programar en Python, R y Julia desde la nube basado en Jupyter Notebooks. Ofrece acceso a recursos computacionales potentes como GPUs y TPUs, permite escribir textos en simultaneo con el codigo y se puede trabajar en grupo simultaneamente

## ¿Cómo se usa?  

### 1. Crear un cuaderno  
   Para crear un cuaderno uno debe acceder a [Google Colab](https://colab.research.google.com), donde un aparecera un pop up con sus cuadernos y la opción de crear uno nuevo.
   
### 2. Configuración  
  Arriba a la izquierda hay un boton llamado "Editar", al hacerle click aparecera un menú desplegabledonde donde debemos seleccionar la opción "Configuración del Cuaderno". Finalmente podemos seleccionar el hardware donde se ejecutara, el lenguaje que usaremos y la version del entorno de ejecución (nosotros seleccionamos CPU, R y la ultima versión)

### 3. Creación de Textos
  Hacer click en "+Texto" para crear una casilla de texto donde podremos anotar lo que necesitemos utilizando el lenguaje Markdown (.md)

### 4. Creación de Código
  Hacer click en "+Código" para crear una casilla de código donde podremos programar usando el lenguaje seleccionado anteriormente

###  5. Guardado  
   Todo se guarda automaticamente en [Google Drive](https://drive.google.com)
